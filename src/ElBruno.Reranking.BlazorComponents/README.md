# ElBruno.Reranking.BlazorComponents

Blazor UI components for semantic reranking scenarios.

## Install

```bash
dotnet add package ElBruno.Reranking.BlazorComponents
```

## Register services

```csharp
builder.Services.AddRerankingBlazorComponents();
```

## Components

- `BackendSelector`
- `RerankResultList`
- `ScoreHeatmap`
- `RerankPlayground`
