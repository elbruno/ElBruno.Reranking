## Usage Guidelines

### For All Images

1. **Branding:**
   - Use consistent color palette: Blues (#0078D4), Purples (#6C3FB5), Whites, with tech accents
   - Include ".NET" branding where applicable
   - Use modern, clean typography

2. **Text Overlay:**
   - Leave 20% margin for text if overlay planned
   - Use high-contrast text on images
   - Keep text readable at small sizes (50% zoom)

3. **Formats:**
   - Export as PNG for transparency
   - Use high quality (300+ DPI for print)
   - Optimize for web (compress without losing quality)

4. **Consistency:**
   - All images should feel part of same brand/product
   - Maintain visual language across all assets
   - Use consistent icon styles and color treatments

### For Social Media

- Twitter: Optimized for 1024×512 or 1200×675
- LinkedIn: 1200×627 px (recommended)
- Facebook: 1200×628 px
- Instagram: 1080×1350 px (square) or 1080×1920 px (story)

### For Web/Docs

- Hero images: 1920×400 px or 1920×1080 px
- Blog: 1200×630 px
- GitHub: 1280×640 px
